Methodology & Assurance

Every number, badge and mapping in this report is derived from a deterministic scan of the source trees at generation time. There are no LLM calls, no judgement calls and no cached state. Re-running the tool against the same source produces the same report.

  • ASPClassic parsing — source extraction of forms, controls, methods, and dependencies from the ASPClassic project.
  • Blazor parsing — regex + XML extraction of @page routes, @inject directives, @code methods, service class methods, model properties, .csproj packages, and Program.cs middleware/DI registrations.
  • Form mapping — name normalization (strip common prefixes), caption↔title matching, route matching, and token-overlap scoring with confidence threshold ≥ 30%.
  • Method mapping — name normalization, event-handler decomposition (stripping handler suffixes), token overlap, and parameter-count similarity bonus.
  • Control mapping — dictionary of 35+ ASPClassic control types → MudBlazor equivalents, verified against actual component usage in matched pages.
  • Scoring — weighted: forms 30%, methods 40%, controls 20%, modernization checks 10%. Grade: A ≥ 90%, B ≥ 80%, C ≥ 70%, D ≥ 60%, F < 60%.
